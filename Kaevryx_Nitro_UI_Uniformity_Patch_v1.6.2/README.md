# Kaevryx Nitro UI Uniformity Patch v1.6.2

Corrige os problemas visuais observados nas telas Fan Control e Lighting:

- sobreposição dos fans com os controles;
- gráfico com triângulo branco;
- curva cortada;
- botões Zone sobrepostos ao preview;
- sliders e labels desalinhados;
- falta de responsividade vertical.

Instalação:

```bash
chmod +x upgrade_ui_uniformity_1.6.2.sh
./upgrade_ui_uniformity_1.6.2.sh
```

O patch substitui somente `knc_gui.py`.
